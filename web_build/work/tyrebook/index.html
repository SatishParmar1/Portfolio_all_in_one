A tyre ERP and marketplace built from scratch for fleet owners and dealers.

About the project

TyreBook tracks tyres through inventory, inspection, fitment, removal, retreading, and claims. I built real-time Firestore synchronisation and role-based access for three or more user roles. I used Provider to address unnecessary re-renders in concurrent sessions and integrated Firebase Analytics and Crashlytics for production monitoring.
