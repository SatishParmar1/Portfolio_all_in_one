Network debugging

API Network Logger

Inspect Dio and http traffic, queue telemetry in SQLite, and redact credentials before they reach your logs.

What it does

Request inspection
Capture network activity through adapters for Dio and the http package.
Offline queue
Keep events in a local SQLite queue when the device is offline.
Credential redaction
Remove sensitive values from logged network data.

Get started

Useful when you need to inspect requests on a device or see what happened when connectivity dropped.

Install with Flutterflutter pub add api_network_logger
